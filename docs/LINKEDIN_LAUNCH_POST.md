I built FolioNest to make creating a personal portfolio easier—and to give people more control over how their work is presented.

You can start without an account, choose from 11 responsive templates, shortlist your favorites, and edit the same content while comparing different designs.

What’s inside:

- Live previews, custom colors, section ordering and optional photo uploads.
- Local autosave and editable JSON backups.
- A one-page A4 résumé, full portfolio PDF, PNG and an independent website ZIP.
- Optional on-device portrait background removal with the original-photo fallback.
- A video walkthrough and illustrated guide for publishing an exported portfolio using free hosting.
- Keyboard-friendly controls and support for reduced motion.

The most interesting challenge was keeping the portfolio consistent across the editor, downloaded files and standalone website. These use the same content model and renderer, and the downloaded ZIP works independently of FolioNest.

Built with React, Vite, Express and Node.js. The architecture also supports optional Supabase authentication and cloud publishing.

Try it: https://folionest.onrender.com
